# 1. Engine Philosophy

The engine is intentionally dumb.

The engine:
- orchestrates
- routes
- persists
- aggregates integer deltas mechanically

The engine does NOT:
- compute scores
- interpret answers
- apply business logic
- rank players
- decide winners
- calculate percentages
- render Host UI
- render Player UI
- define Host UI behavior
- define Player UI behavior

All game logic belongs to plugins.
Host UI and Player UI are 100% plugin-owned.

---

# 2. Integer-Only Scoring

Scoring is strictly defined by:

docs/contracts/scoreEntry_contract_v1.md

Rules:

- No floats
- No percentages
- No derived values
- No score formulas in engine
- No ranking logic in engine

Only ScoreEntry is allowed.

---

# 3. No Duplicate Contracts

Codex must not:

- Redefine StageOutcome
- Redefine ScoreEntry
- Introduce ScoreDelta or GradeDelta
- Introduce float-based scoring
- Create alternative runtime schemas

All runtime structures must match:

docs/contracts/runtime_schema_v1.md

---

# 4. Determinism

Plugins must be deterministic.

Given:
- same config
- same seed
- same inputs

resolve() must return identical StageOutcome.

Engine must not inject randomness.

---

# 5. WebSocket Format

All WS messages must follow:

{
  "type": "EVENT_NAME",
  "payload": { ... }
}

No alternative envelope allowed.

---

# 6. Engine Boundaries

Engine may:

- Aggregate delta_score mechanically
- Expose total snapshots
- Emit host overlays

Engine must not:

- Sort players
- Compute podiums
- Compute winners
- Apply scoring rules

---

# 7. Plugin Boundaries

Plugins must:

- Implement StageRuntime interface
- Return valid StageOutcome
- Use integer-only scoring
- Use provided seed

Plugins must not:

- Access engine storage
- Modify session state
- Inject floats

---

The canonical schema authority order is defined in:

docs/contracts/README.md (section: Contract Hierarchy)

# 9. What Codex Must Never Do

Codex must never:

- Add business logic to engine
- Add ranking features to engine
- Add float scoring
- Redesign StageOutcome
- Introduce alternative WS envelopes
- Mix plugin logic into engine

If Codex is unsure:
